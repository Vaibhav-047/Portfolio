# Freefall reference

The active site adapts the original HTML, CSS, and scroll engine from https://github.com/gireeshkumarreddy/freefall-portfolio-code and the original fall/portal frames from its linked full project, https://github.com/gireeshkumarreddy/freefall-portfolio . Original project by gireeshkumarreddy; downloaded October 29, 2026.

Personalization changes the name, biography, location/timezone, professional title, toolkit, contact links, and selected project content to Vaibhav Tripathi. There are two actual project entries rather than the reference's four fictional cases. Unknown project details remain marked as pending. Reference film artwork is decorative and is not represented as screenshots of Vaibhav's projects.

The active page is `index.html`, its original scroll engine is `src/reference-main.js`, and the reference stylesheet is `public/reference/style.css`. Original film sequences are in `public/assets/fall/` (465 frames) and `public/assets/portal/` (239 frames). Fonts and Lenis are self-hosted, with dependency licenses beside them. No Iron Man components are imported by the active page.

Run `npm run dev -- --host 127.0.0.1 --port 5173`. Build the static site with `npm run build`. Previous React implementations remain in the source history/workspace for recovery; they are not loaded by this page.
